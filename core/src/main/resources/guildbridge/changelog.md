## 0.3.1
- Profile commands now work in Discord too. Add a username, or link your account with /verify to skip it.
- New /verify: link your Discord and Minecraft accounts with a code you whisper to the bridge in game. /unlink removes it.
- In-game commands no longer get ignored during the cooldown. They wait in line and are answered in order, 7 seconds apart.
- Emoji from Discord show up in game: simple symbols like ❤ stay as they are, others show their name, like :skull:.
- New !patch (Discord only): shows what changed in the latest version.

## 0.2.1
- The bridge waits for the game to finish loading before joining Hypixel.
- If the connection gets stuck, the game restarts by itself.
